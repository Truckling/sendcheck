Two ways to use it

Over HTTP, from any agent

Add the MCP server to Claude Code, Claude.ai or any MCP client. Nothing to install. Your agent calls check_message before it sends and acts on the verdict.

Locally, from Python

Run the same checks offline in a script or pipeline. The local server also keeps an evidence log of every check on your machine.

# Claude Code, over HTTP
claude mcp add --transport http truvek-comply https://truvek.io/comply/mcp

# Claude.ai or another MCP client: add a custom connector with this URL
https://truvek.io/comply/mcp

# Local, from Python
pip install truvek-comply
claude mcp add truvek-comply truvek-comply

Connect your platform

HTTP API

POST to https://truvek.io/check from any CRM, pipeline, or pre-send hook. No SDK or account needed. Returns verdict, findings by jurisdiction, and fix guidance in JSON.

Response fields

verdict is pass, review, or block. Gate your send on block. Queue for review on review. Each finding has a rule, a plain title, the laws it falls under as scope, and the fix. next_tool says what to call next. Same shape as every Truvek tool.

# Request
curl -X POST https://truvek.io/check \
  -H "Content-Type: application/json" \
  -d '{
    "subject": "Your order has shipped",
    "body": "Full message text here...",
    "channel": "email",
    "consent": "express",
    "sender_identified": true
  }'

# Response
{
  "verdict": "pass",
  "findings": [],
  "next_tool": "deliver_send_requirements",
  "next_tool_server": "https://design.truvek.io/mcp",
  "classification": { "type": "transactional" }
}
FieldTypeValues
subjectstringEmail subject line. Leave empty for SMS.
bodystringFull message body, plain text.
channelstringemail or sms. Default: email.
consentstringexpress, inferred, none, or unknown. Default: unknown.
sender_identifiedbooleanTrue if the sender's name and contact details appear in the message.

Pair it with Truvek Design

Comply checks what the email says. Truvek Design makes sure it renders in Outlook, Gmail, Apple Mail and dark mode. Connect the Truvek endpoint and an agent builds the email, fixes it until it displays properly in every inbox, then clears it here before it sends.

# one endpoint for every Truvek tool
claude mcp add --transport http truvek https://truvek.io/mcp

# the loop an agent runs
design_compile(layout, dialect)           # repeat until the verdict is not block
comply_check_message(subject, body, consent)
deliver_send_requirements(provider)       # if your app sends its own mail

What non-compliance costs

ACMA has issued fines over 7 million AUD for consent failures, and 700K AUD for transactional emails containing promotional content. The FTC enforces CAN-SPAM with civil penalties of up to 53,088 USD per email (Federal Register, 17 January 2025, unchanged for 2026). CRTC enforces CASL with penalties up to 10 million CAD per violation.

Truvek Comply is a pre-send compliance tool, not legal advice.
