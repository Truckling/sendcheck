Usage

Two ways to use it

Ask Claude in plain English

Add the MCP server to Claude Desktop or Claude.ai and ask it to check your email. Claude calls the tool, reads the findings, and explains what needs to change and why.

Call the API directly

Import truvek_comply into any Python script or pipeline. Returns structured JSON: verdict, findings tagged by law, and suggested fixes.

# Claude Desktop — claude_desktop_config.json
{
  "mcpServers": {
    "truvek-comply": {
      "command": "truvek-comply"
    }
  }
}

# Claude Code
claude mcp add truvek-comply truvek-comply
Context

The stakes

ACMA has issued fines over 7 million AUD for consent failures and 700K AUD for transactional emails containing promotional content. The FTC enforces CAN-SPAM with fines up to 51,744 USD per email. CRTC enforces CASL with penalties up to 10 million CAD per violation.

Truvek Comply is a pre-send compliance tool, not legal advice.
