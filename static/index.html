Tools for agents that send email.

One MCP endpoint covers the whole job. Your agent builds the email, checks it displays properly in every inbox, checks the words against spam and privacy law, then sets up the send.

Add to Claude Tool reference
claude mcp add --transport http truvek https://truvek.io/mcp

Streamable HTTP. No account, 120 requests a minute per IP.

  1. Build

    design_compile

    A layout in, HTML out for Klaviyo, Braze, Marketing Cloud, Shopify, SendGrid or your own app.

  2. Check the design

    design_lint

    51 checks for what breaks in Outlook, Gmail, on phones, in dark mode and for screen readers, each with the line and the fix.

  3. Check the words

    comply_check_message

    The Spam Act, CAN-SPAM, CASL, GDPR and the TCPA: consent, sender details, unsubscribe.

  4. Set up sending

    deliver_send_requirements

    List-Unsubscribe headers, one-click unsubscribe and DNS for Resend, SES, Postmark and others.

Each step returns verdict, findings and next_tool, so the agent knows what to call next.

Two products behind one endpoint

  • Design

    Turns a screenshot, Figma frame or brief into email HTML that holds up in Outlook, Gmail, Apple Mail and dark mode. Checks any email HTML for what will break, including emails other tools generate.

    design_compile, design_lint, design_autofix and five more

    About Design

  • Comply

    Checks email and SMS copy against spam and privacy law in Australia, the US, Canada and the EU before it sends. Catches promotions hiding in transactional email.

    comply_check_message, comply_classify_message and two more

    About Comply

The same answer from every tool

Every response leads with a verdict, a list of findings and the tool to call next. An agent can gate on block, fix what each finding says, and follow next_tool to the end of the loop.
